# Installation

Get CX Linux running on your system in under 5 minutes. Choose your preferred installation method below.

## System Requirements

Before installing, ensure your system meets these minimum requirements:

| Requirement | Minimum | Recommended |
|-------------|---------|-------------|
| Architecture | x86_64 (amd64) | x86_64 (amd64) |
| RAM | 2 GB | 4 GB+ |
| Storage | 500 MB | 1 GB |
| OS | Linux kernel 5.4+ | Latest LTS kernel |

## Quick Install (Recommended)

The fastest way to install CX Linux is using our install script:

```bash title="Install CX Linux"
curl -fsSL https://cxlinux.com/install.sh | bash
```

This script automatically:
- Detects your distribution and package manager
- Installs all required dependencies
- Configures your AI backend
- Sets up shell completions

## Package Manager Installation

<Tabs>
  <TabItem value="apt" label="Debian/Ubuntu" default>

```bash
# Add the CX Linux repository
sudo apt-get update
sudo apt-get install -y apt-transport-https ca-certificates curl gnupg

curl -fsSL https://repo.cxlinux.com/key.gpg | sudo gpg --dearmor -o /etc/apt/keyrings/cxlinux.gpg

echo "deb [signed-by=/etc/apt/keyrings/cxlinux.gpg] https://repo.cxlinux.com/apt stable main" | \
  sudo tee /etc/apt/sources.list.d/cxlinux.list

# Install CX Linux
sudo apt-get update
sudo apt-get install cx-terminal
```

  </TabItem>
  <TabItem value="dnf" label="Fedora/RHEL">

```bash
# Add the CX Linux repository
sudo dnf config-manager --add-repo https://rpm.cxlinux.com/cx.repo

# Install CX Linux
sudo dnf install cx
```

  </TabItem>
  <TabItem value="pacman" label="Arch Linux">

```bash
# Install from AUR using yay
yay -S cx-bin

# Or using paru
paru -S cx-bin
```

  </TabItem>
</Tabs>

## Building from Source

For developers or those who want the latest features:

```bash
# Clone the repository
git clone https://github.com/cxlinux-ai/cx-core.git
cd cx-core

# Build with Cargo (requires Rust toolchain)
cargo build --release

# Install the binary
sudo cp target/release/cx /usr/local/bin/

# Verify installation
cx --version
```

:::note Rust Toolchain
If you don't have Rust installed, get it from [rustup.rs](https://rustup.rs/):
```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```
:::

## Verify Installation

After installation, verify that CX Linux is working correctly:

```bash
# Check version
cx --version
# highlight-next-line
# Output: CX Linux v0.3.x

# Run a test command
cx status
```

## Post-Installation Setup

After installing, you'll need to configure your AI backend. See the [Configuration](/docs/getting-started/configuration) guide for details.

:::tip Shell Completions
Enable shell completions for a better experience:

```bash
# Bash
cx completion bash >> ~/.bashrc

# Zsh
cx completion zsh >> ~/.zshrc

# Fish
cx completion fish > ~/.config/fish/completions/cx.fish
```
:::

## Troubleshooting

### Common Issues

<details>
<summary>Command not found: cx</summary>

Ensure the installation directory is in your PATH:

```bash
export PATH="/usr/local/bin:$PATH"
```

Add this line to your shell configuration file (`~/.bashrc`, `~/.zshrc`, etc.).

</details>

<details>
<summary>Permission denied during installation</summary>

Make sure you have sudo privileges, or install to a user-writable location:

```bash
# Install to ~/.local/bin instead
mkdir -p ~/.local/bin
cp target/release/cx ~/.local/bin/
```

</details>

<details>
<summary>Build fails with cargo</summary>

Ensure you have the latest Rust toolchain:

```bash
rustup update
```

You may also need build essentials:

```bash
# Debian/Ubuntu
sudo apt install build-essential pkg-config libssl-dev

# Fedora
sudo dnf install gcc pkg-config openssl-devel
```

</details>

## Uninstallation

To remove CX Linux from your system:

<Tabs>
  <TabItem value="apt" label="Debian/Ubuntu" default>

```bash
sudo apt-get remove cx-terminal
sudo rm /etc/apt/sources.list.d/cxlinux.list
sudo rm /etc/apt/keyrings/cxlinux.gpg
```

  </TabItem>
  <TabItem value="dnf" label="Fedora/RHEL">

```bash
sudo dnf remove cx
```

  </TabItem>
  <TabItem value="manual" label="Manual Install">

```bash
sudo rm /usr/local/bin/cx
```

  </TabItem>
</Tabs>
